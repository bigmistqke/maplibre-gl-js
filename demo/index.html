MapLibre Mini / demos

Phase 1 Background Layer Solid color fill, camera controls, the render loop. Phase 2 Raster Tiles WebGL tile rendering with MercatorProjection. Tiles fetched on the main thread. Phase 3 Tile Eviction FIFO tile cache with GPU memory eviction. Watch tile count stay bounded as you zoom. Phase 4 Worker Tile Service Tile fetching and ImageBitmap decoding offloaded to a Comlink Web Worker. Phase 5 Vector Tiles MVT polygon fill and line rendering with earcut tessellation. Tile decode in a Comlink worker. Phase 6 Globe Projection Spherical globe with raster tiles, bearing, pitch, and auto-rotation. Subdivision mesh from MapLibre.
